# Поэтапный план создания калькулятора (QML + C++)

*Обновленный план: сначала создаем визуальную часть (интерфейс), а затем подключаем к ней C++ логику (бэкенд).*

## Этап 1: Создание визуальной части (QML Frontend)
*   **Цель:** Сделать полностью готовый, красивый интерфейс (макет), который реагирует на нажатия, но пока не умеет считать.
*   **Детальные шаги:**
    1.  **Настройка базового окна (`Main.qml`):**
        *   Задать строгие размеры окна (например, ширина 320, высота 500), запретить изменение размеров, чтобы верстка не "поехала".
        *   Выбрать стильный цвет фона (например, темно-серый или почти черный).
    2.  **Создание компонента дисплея:**
        *   Выделить верхнюю часть окна под "экран".
        *   Использовать `Text` для отображения вводимого текста, настроить крупный, красивый шрифт, выровнять текст по правому краю.
        *   Пока поставить туда заглушку (например, "0").
    3.  **Создание собственного компонента кнопки (`CalcButton.qml`):**
        *   Вместо скучных стандартных кнопок, создать отдельный QML-файл.
        *   Внутри него использовать `Rectangle` (для формы) и `Text` (для надписи).
        *   Добавить параметры (properties), чтобы можно было задавать кнопке разный цвет (для цифр — один, для операций — другой, для "=" — яркий акцент).
        *   С помощью `MouseArea` добавить обработку кликов.
        *   Сделать анимации: при наведении (hover) кнопка чуть светлеет, при нажатии (press) — визуально "продавливается".
    4.  **Сборка сетки кнопок (Клавиатура):**
        *   В `Main.qml` добавить `GridLayout` на 4 колонки.
        *   Расположить все кнопки по своим местам: цифры 0-9, точку, арифметические операции (`+`, `-`, `*`, `/`), очистку (`C`, `CE`) и знак равно (`=`).
        *   Назначить каждой кнопке временное действие — вывод текста в консоль (например, `console.log("Нажата цифра 5")`), чтобы убедиться, что клики работают.

## Этап 2: Проектирование C++ Backend-а (Логика калькулятора)
*   **Цель:** Написать "мозг", который будет выполнять реальные вычисления и хранить состояния.
*   **Детальные шаги:**
    1.  **Создание файлов:** Создать `calculatorbackend.h` и `calculatorbackend.cpp`.
    2.  **Структура класса:** Унаследовать класс `CalculatorBackend` от `QObject`.
    3.  **Свойства (Properties) для UI:**
        *   Определить макрос `Q_PROPERTY(QString displayValue READ displayValue NOTIFY displayValueChanged)`. 
        *   Это свойство будет хранить то, что должно быть написано на экране калькулятора.
    4.  **Внутренние переменные (State):**
        *   `QString m_displayValue` — текущая строка ввода.
        *   `double m_previousValue` — предыдущее введенное число, сохраненное для операции.
        *   `QString m_currentOperation` — какая операция была выбрана (`+`, `-`, `*`, `/`).
        *   `bool m_waitingForNewOperand` — флаг, указывающий, нужно ли стереть экран при вводе следующей цифры (например, сразу после нажатия "+").
    5.  **Методы-обработчики (`Q_INVOKABLE`):**
        *   Создать методы, которые QML сможет вызывать напрямую:
            *   `Q_INVOKABLE void digitPressed(int digit);`
            *   `Q_INVOKABLE void operationPressed(const QString& op);`
            *   `Q_INVOKABLE void calculateResult();`
            *   `Q_INVOKABLE void clearAll();`
            *   `Q_INVOKABLE void decimalPointPressed();`
    6.  **Реализация математики:** Написать код внутри `.cpp` файла для каждого метода, чтобы числа корректно складывались, вычитались и обрабатывались краевые случаи (например, деление на ноль должно выводить "Error").

## Этап 3: Интеграция интерфейса и логики
*   **Цель:** Заставить красивые кнопки вызывать реальный C++ код.
*   **Детальные шаги:**
    1.  **Регистрация C++:** Добавить макрос `QML_ELEMENT` в заголовок `CalculatorBackend`, чтобы QML-движок увидел этот класс как готовый компонент.
    2.  **Обновление сборки:** Убедиться, что `CMakeLists.txt` компилирует новые файлы `.cpp` (добавить `calculatorbackend.cpp` в `qt_add_executable`).
    3.  **Инициализация в QML:**
        *   В `Main.qml` создать объект логики: `CalculatorBackend { id: backend }`.
    4.  **Связывание дисплея:**
        *   В компоненте экрана заменить заглушку "0" на `text: backend.displayValue`. Теперь дисплей будет сам автоматически обновляться при расчетах!
    5.  **Связывание кнопок:**
        *   Вместо `console.log()` прописать в обработчиках кнопок вызовы методов C++.
        *   Например, для кнопки "7": `onClicked: backend.digitPressed(7)`.
        *   Для кнопки "+": `onClicked: backend.operationPressed("+")`.
        *   Для кнопки "=": `onClicked: backend.calculateResult()`.

## Этап 4: Полировка (Финальные штрихи)
*   **Цель:** Довести приложение до идеала.
*   **Детальные шаги:**
    1.  **Ввод с клавиатуры:** Добавить элемент `Item` с `focus: true` и обработчиком `Keys.onPressed`, чтобы можно было набирать числа и нажимать Enter прямо с клавиатуры компьютера.
    2.  **Масштабирование текста:** Реализовать логику в QML, которая уменьшает размер шрифта (`font.pixelSize`) на дисплее, если введено очень длинное число и оно не помещается в ширину экрана.
    3.  **Дополнительные операции:** По желанию добавить кнопки "+/-" (смена знака) и "%" (процент).
