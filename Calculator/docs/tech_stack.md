# Технологический стек калькулятора (QML + C++)

## Базовые технологии
*   **Языки программирования:** 
    *   **C++ (C++17/20)** — используется для написания вычислительного ядра (Backend), бизнес-логики и управления состояниями. Это обеспечивает высокую производительность и строгую типизацию.
    *   **QML (Qt Meta-Object Language)** — декларативный язык для создания пользовательского интерфейса (Frontend). Обеспечивает гибкость, анимации и быстрое прототипирование.
*   **Фреймворк:** **Qt 6**
    *   Модули: `QtCore`, `QtGui`, `QtQml`, `QtQuick`, `QtQuickControls2`.
*   **Система сборки:** **CMake**
    *   Официальный стандарт для сборки C++ проектов и основной инструмент сборки, рекомендованный в Qt 6.

## Архитектура и паттерны (MVVM-подобная структура)
*   **Model/ViewModel (C++):** Класс `CalculatorBackend`, унаследованный от `QObject`.
    *   `Q_PROPERTY` — механизм для привязки данных. Позволяет UI автоматически обновляться при изменении значения в C++ (например, текущего числа на экране).
    *   `Q_INVOKABLE` / `slots` — методы C++, которые можно вызывать напрямую из QML при нажатии на кнопки.
    *   Макрос `QML_ELEMENT` — современный (Qt 6) способ регистрации C++ классов в QML.
*   **View (QML):** Файлы интерфейса (например, `Main.qml`).
    *   Они ничего не знают о том, *как* складывать числа. Их задача — отрисовать кнопки, поймать клик пользователя и передать команду в C++ Backend, а затем отобразить результат, который Backend положит в свойство (Property).

## Компоненты UI (Qt Quick Controls)
*   `GridLayout` — для создания сетки кнопок (цифры, операции).
*   `Rectangle` / `Button` — для самих кнопок. Будем стилизовать их для создания современного дизайна.
*   `Text` / `Label` — для отображения вводимых данных и результата (дисплей калькулятора).
