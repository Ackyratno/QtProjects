# 🛠 Tech Stack — To-Do List

## Язык программирования

### C++
- **Зачем:** Основной язык для логики приложения (бэкенд). Здесь ты будешь описывать модели данных, работу с файлами, бизнес-логику.
- **Что изучишь:** классы, наследование, сигналы/слоты Qt, работа с контейнерами (`QList`, `QVariantMap`).

---

## Фреймворк

### Qt 6 (Qt Quick)
- **Зачем:** Qt — это кроссплатформенный фреймворк для создания приложений с графическим интерфейсом. Qt Quick — модуль Qt для создания современных UI через QML.
- **Что изучишь:** структура Qt-проекта, система сборки CMake, модуль Qt Quick.

---

## UI (Интерфейс)

### QML (Qt Modeling Language)
- **Зачем:** Декларативный язык для описания интерфейса. Похож на JSON/CSS — ты описываешь *что* показать, а не *как* рисовать.
- **Что изучишь:** компоненты (`Rectangle`, `Text`, `MouseArea`), привязки свойств (property bindings), анимации, `ListView`, `Delegate`.

---

## Модель данных

### QAbstractListModel (C++)
- **Зачем:** Стандартный способ Qt для передачи списка данных из C++ в QML. Когда ты добавляешь/удаляешь задачу в C++, QML автоматически обновляет интерфейс.
- **Что изучишь:** паттерн Model-View, роли (roles), переопределение виртуальных методов (`rowCount`, `data`, `roleNames`).

---

## Хранение данных

### JSON (файл на диске)
- **Зачем:** Простой и читаемый формат для сохранения задач между запусками приложения. Никакой базы данных — просто файл `tasks.json`.
- **Что изучишь:** `QJsonDocument`, `QJsonArray`, `QJsonObject`, чтение/запись файлов через `QFile`.

---

## Система сборки

### CMake
- **Зачем:** Стандартная система сборки для Qt 6 проектов. Описывает какие файлы компилировать, какие библиотеки подключать.
- **Что изучишь:** базовая структура `CMakeLists.txt`, подключение Qt модулей, добавление QML файлов в проект.

## Связь C++ ↔ QML

```
QML вызывает C++ метод:       todoModel.addTask("Купить молоко")
C++ уведомляет QML:           beginInsertRows() → endInsertRows()
QML автоматически обновляет:   ListView перерисовывает список
```

> **Ключевая идея:** QML отвечает за *как выглядит*, C++ отвечает за *как работает*.
