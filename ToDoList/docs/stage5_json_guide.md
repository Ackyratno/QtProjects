# Этап 5: Сохранение и загрузка данных (JSON)

Здесь описаны шаги, которые вам нужно выполнить **самостоятельно**, чтобы научить приложение запоминать ваши задачи. Постарайтесь перевести эти словесные инструкции в код C++.

## Шаг 1: Подготовка (Заголовочный файл `todomodel.h`)
1. Добавьте необходимые инклуды для работы с JSON и файлами: `QJsonObject`, `QJsonArray`, `QJsonDocument`, `QFile`, `QIODevice`.
2. В секции `private` (или `public`, если хотите) объявите два новых метода:
   * Метод для сохранения: `void saveToFile() const;`
   * Метод для загрузки: `void loadFromFile();`

## Шаг 2: Реализация сохранения (`todomodel.cpp`)
Создайте тело функции `saveToFile()`. Ваша логика внутри:
1. Создайте пустой массив (объект класса `QJsonArray`).
2. Напишите цикл `for`, который пройдет по всем элементам вашего списка `m_items`.
3. Внутри цикла:
   * Создайте пустую коробку (объект `QJsonObject`).
   * Положите в нее описание (ключ `"description"`) и статус (ключ `"isDone"`).
   * Положите эту коробку в ваш массив `QJsonArray` (используйте метод `append`).
4. Когда цикл завершится, создайте документ (`QJsonDocument`) и передайте в него ваш заполненный массив.
5. Создайте объект файла (`QFile`). В качестве имени файла передайте строку, например `"tasks.json"`.
6. Откройте файл в режиме "только для записи" (`QIODevice::WriteOnly`).
7. Запишите в файл ваш документ (у документа есть метод `toJson()`, который возвращает текст).
8. Закройте файл (метод `close()`).

## Шаг 3: Автоматизация сохранения
Теперь нужно сделать так, чтобы файл обновлялся каждый раз, когда данные меняются.
1. Найдите метод `addTask` и добавьте вызов `saveToFile()` в самый конец функции.
2. Найдите метод `removeItem` и тоже добавьте вызов `saveToFile()` в конец.
3. Найдите метод `setData` и добавьте вызов `saveToFile()` внутрь условия, где вы успешно изменили статус `isDone`.

## Шаг 4: Реализация загрузки (`todomodel.cpp`)
Создайте тело функции `loadFromFile()`. Логика внутри:
1. Создайте объект файла (`QFile`) с тем же именем `"tasks.json"`.
2. Попробуйте открыть его в режиме "только для чтения" (`QIODevice::ReadOnly`). Если файл не открылся (например, вы запустили программу первый раз и файла еще нет) — просто прервите функцию (напишите `return;`).
3. Считайте весь текст из файла (у файла есть метод `readAll()`) и сохраните его в переменную типа `QByteArray`.
4. Закройте файл.
5. Создайте `QJsonDocument`, передав в него ваш считанный текст (для этого используется статическая функция `fromJson`).
6. Достаньте из документа массив (метод `array()`) и сохраните его в переменную типа `QJsonArray`.
7. Запустите цикл `for`, который пройдет по всем элементам этого `QJsonArray`.
8. Внутри цикла:
   * Возьмите текущий элемент и превратите его в объект (`QJsonObject`).
   * Достаньте из объекта строку по ключу `"description"`.
   * Достаньте из объекта булево значение по ключу `"isDone"`.
   * Добавьте эти данные в ваш настоящий массив `m_items` (можно использовать обычный `m_items.append(...)`, так как мы будем вызывать эту функцию до отрисовки интерфейса).

## Шаг 5: Загрузка при старте программы
1. Найдите **конструктор** вашего класса `ToDoModel` (это самая первая функция в `todomodel.cpp`).
2. Удалите оттуда тестовые задачи (про молоко и QML), которые мы писали на втором этапе.
3. Вместо них просто вызовите метод `loadFromFile()`.
